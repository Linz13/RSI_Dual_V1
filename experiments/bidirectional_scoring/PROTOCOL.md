# 实验协议 v1

## 范围与来源

- 仅情绪：happy / sad / angry / neutral，使用相同中文描述模板。A 经人工修正到其他明确情绪时使用修正后的值，自动构造三个不同情绪负例；不会强迫人工采用来源标签。模糊／混合／不可用单列。
- A：EmotionTalk 官方 speaker-independent test。中文转写来自官方 transcription，情绪标签仅用于分层抽样；人工完成最终可听情绪、转写核验。按标签均衡、说话者交错，固定种子，最后打乱展示顺序。旧 smoke 的时长范围为 1–15 秒；新 `pilot30` 为 4–15 秒，减轻片段过短的问题，不能据此认定情绪明确。原始标签、转写、speaker、session、split、音频 SHA256 均保留在私有清单。
- A 不是未被旧项目看过的全新测试集。与旧 `training_data/audio` 进行字节 SHA256 比较，不把字节不重叠写成无感知重复或无预训练暴露。该集总共四位说话者，pilot 结论的说话者覆盖有限。
- B：默认取 V5 LabelRobust `round_000` 的现有四候选。只按条件元数据、目标类别、语言、文件完整性、时长 1–20 秒选择，不读 reward、偏好或模型评分。只使用中文请求，排除明显的请求语言／文本冲突。单独记录过滤数量；这不是用 ASR 自动确认内容正确。
- B 评分只评价原完整指令中的情绪属性；其他生成条件在组内不变，不声称验证完整多属性指令。源生成命令、种子、配置文件及 rollout 哈希可追溯；首轮命令无 checkpoint 参数且配置 adapter_path 为空，使用 Qwen3-TTS 基础模型。保留历史训练使用标记。
- 每个样本包冻结顺序、音频和身份；重新准备使用新目录。新增完整 pilot 不会自动运行。未来包与已准备包的字节重叠会记录在 `previous_pilot_matches`。
- `pilot30` 已准备 A 30 条、B 30 组，每组四条；四种来源／目标情绪各 7–8 个。显式排除 `smoke01` 的来源 ID 和音频字节 SHA256。抽样不读取模型分数，也不预先按人工偏好筛出有差异的 B 组。30 是待核验数量，不保证最终有效数或必然出现评分信号；不自动补样或扩大规模。

## A 的评分

Qwen3-TTS-12Hz-1.7B-VoiceDesign 基础模型，无 LoRA、参考音频、训练器。

1. 复用旧代码中已经核对过的三个纯条件构造函数，独立保存在 `qwen_conditioning.py`，附来源路径与 SHA256；没有导入旧 worker 初始化、reward、训练、旧缓存管理。
2. 使用模型自身 speech tokenizer，24 kHz 输入，16 个有效码本。预处理保留完整音频，单条编码；缓存记录音频及评分身份。目标是离散 codec，不是 waveform density。
3. 固定真实 codec、核验文本及语言，仅改变风格指令。真实音频 token 作为因果 teacher-forcing 前缀，不作为声纹参考条件。
4. 主码本取 `prefix_length-1 : prefix_length-1+T` 的下一 token logits；子码本使用对应主 talker hidden state 和同帧此前码本。按实际 `16T` 个目标 token 计算平均 log-probability。
5. 使用原始 logits，softmax 在 FP32、汇总在 FP64。无 temperature/top-k/repetition penalty 等采样变换；不计文本、风格描述、codec BOS/EOS、padding。此数值不含终止概率，不是完整变长语音概率。
6. 保存逐帧逐码本分数、每码本均分和旧加权分 `main_mean+0.3*sub_mean`，后者仅作历史口径对照，不参与主排序。

真实音频前缀是否削弱指令影响仍是科学问题，不由“接口能计算”推断评分有效。

## B 的评分

MiDashengLM-7B-1021-BF16 基础模型，无 adapter。采用目标文本条件概率，不生成 caption，不使用新 LLM judge。

- user 输入只有音频和固定通用提示，提示不包含目标情绪或转写；目标描述仅是 assistant 中被评分的正文。
- processor 分别构建提示、完整目标、空 assistant 尾部；要求前缀、独立正文 token 和聊天后缀精确对齐，不使用字符串搜索猜测 mask。
- 使用原始 logits 的下一 token 分布，仅平均描述正文。排除角色符号、提示、音频占位、`im_end` 和后续换行；保存 token ID、token 字符片段、log-probability、目标起止位置。
- 当前四种描述长度接近且模板一致；每组目标完全相同。不是旧的字段宏平均，不加入转写、反事实或冻结基模综合奖励。

## 独立人工参照与统计

- A 页面不展示来源情绪作为默认答案，人工明确选择情绪并核对转写，点击“下一条”即保存为已完成，支持返回修改，不再另设确认按钮。未完成、无法判定、不可用、模型报错、缺失、标注变更后的过期评分分别记录，不填零。
- B 页面只含目标情绪、生成文本、固定随机顺序的音频。原候选 ID、模型来源细节、reward、模型排名、分数均不进入页面或 ZIP。服务器不公开私有清单和评分目录。
- B 支持最佳集合（允许并列）、全部不合格、无法判断。模型最高分集合 M 若平局，命中人工最佳 H 的统计按 `|M∩H|/|M|`，相应均匀随机基线为 `|H|/K`；避免按文件顺序破平局。
- 四条都合格仍可有优劣；只有同样符合且没有明显优劣时选“四条并列最佳”。这类组的命中率和随机基线均为 100%，不能提供相对排序证据。报告同时列出全部可比较组及人工最佳集合小于 K 的子集，不隐藏全并列组。
- 全部不合格和无法判断不计入“有合格最佳集合”的命中率分母，但始终单列数量；本评分没有经过标定的绝对合格阈值，不能声称模型能自动拒绝全部不合格组。
- A 输出严格 top1、并列第一、排名、逐负例分差、胜负平，以及情绪类别拆分。B 输出每组排名、模型／人工平局、命中率、随机基线、差值和按组 bootstrap 的描述性区间。无独立人工偏好时不声称有效。
- 默认平局容差 `1e-5`，写入报告。报告附 `1e-4`、`1e-3` 的平局敏感性结果，避免隐去非常小的分差。小规模 smoke 用于验证执行链路，不作为总体有效性结论。

## 条件与数值检查

- v3 A 精度对照：仅在用户显式传入 `--score-dtype float32` 时，将以 BF16 加载的同一份 talker 权重（包含子码本预测器）在内存中转为 FP32，独立 speech tokenizer 不转换。不是恢复权重存储前丢失的精度；检验的是前向计算误差。替代路径阈值收紧为 `1e-4`，重复与 padding 内容检查仍为 `1e-5`。精度进入评分身份，目标 codec 哈希进入数值检查。B 的已完成 v2 结果保持原口径，可以通过显式 A/B 来源标签合并报告，无需重跑 B。
- 数值实现 v2：模型仍为 BF16；所有评分／独立前缀检查以及音频编码使用固定 SDPA math 后端，关闭 TF32、BF16 GEMM 的低精度归约与 SDPA math 的低精度归约。环境、GPU 名称、后端和开关写入检查记录；不修改模型文件和已安装环境。`--sdpa-backend auto` 仅保留为显式诊断选项，配置差异进入结果身份。
- 首个真实评分样本：重复评分（最大差 `1e-5`）；添加被 mask 的尾部 padding；A 首帧独立顺序码本检查及改变未来音频帧；B 每个目标 token 单独只输入此前正文的 forward 检查。实际误差全部保存。
- 不同长度／计算路径的 BF16 结果可能不同，替代计算路径允许最大差 `0.05`；这个限值只作实现排障，不是可忽略的风格差值。报告保留误差与小分差敏感性，不能据此断言微小排序稳健。v1 的真实 A、B 超限后停止；v2 没有放宽阈值，是否排除该差异需真实运行核验。
- v2 增加保持形状和 mask 不变、只改 padding 内容的检查（最大差 `1e-5`）；A 另比较相同 talker hidden 下的逐码本与并行子码本路径，区分主模型和子模型误差。保存各路径目标 log-probability、最大 token 误差、平均绝对误差及有符号平均分漂移。检查失败或抛异常时先写文件再停止；已有失败检查不能解锁评分。
- 默认前两个组保留条件对照：A 无指令、其他样本转写；B 第一候选的错误情绪文本及其他组音频。对照分数仅用于检查条件依赖，没有独立音频标签时不认定某个方向必须为正。
- 数值检查失败会停止并保留详细日志。中断可恢复已完成样本；身份变化使用新 tag，不覆盖旧评分。

## 不自动执行的操作

不训练、不生成偏好训练对、不启动多轮、不安装依赖、不下载模型、不调用 API。真实模型命令只由用户执行，并必须指定 GPU。轻量准备／页面／汇总不 import torch；独立 processor 验收仅在 CPU，不加载权重。
