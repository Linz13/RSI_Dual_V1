# smoke01 双向流程验收与结果解读

## 本次可以确认什么

**当前配置下，小规模双向执行流程已跑通。**A 使用 FP32 talker、math SDPA（`v3_fp32`），已完成 4/4 条；B 复用已完成的 BF16、math SDPA（`v2`），4/4 组／16 条。合并汇总、逐样本分数、数值诊断和 20 个音频的试听包完整。没有训练或自动运行新 30+30 pilot。

这里的“跑通”指：人工标注可以保存、模型可以完成评分、预设首样本数值检查通过、结果可以对照人工参照并汇总。它不等于两个评分方向都有效，也不代表已经验证任意长度、设备、批大小或后续互相训练。

## A：出现初步正向排序信号，但有一条接近并列

| 样本 | 人工核验情绪 | 模型最高分情绪 | 相对最强错误描述的分差 |
|---|---|---|---:|
| A001 | 平静 | 平静 | +0.019856（对开心） |
| A002 | 悲伤 | 悲伤 | +0.004318（对平静） |
| A003 | 愤怒 | 愤怒 | +0.00003458（对平静） |
| A004 | 平静 | 平静 | +0.023684（对开心） |

按预设 `1e-5` 平局容差，正确描述 4/4 严格第一，12 个正负比较均胜，无无效评分。按报告中已经预设的 `1e-4` 或 `1e-3` 敏感性口径，则为 **3 条严格第一 + A003 并列第一**。没有改动原分数或默认判定；不能把 A003 的微小领先当作强证据。

每条音频的三个比较共享同一输入，12 次胜利不是 12 条独立样本。人工正标签分布为平静 2、悲伤 1、愤怒 1，没有开心正例；其中两个短片段此前也被用户指出难以判断。这是流程试运行和初步信号，尚不足以估计总体准确率。

### A 的条件对照

| 样本 | 正确描述 − 无描述 | 正确转写 − 错配转写 |
|---|---:|---:|
| A001 | −0.013287 | +0.215282 |
| A002 | −0.012413 | +0.162442 |

错配转写降低了分数，支持评分依赖转写条件。另一方面，两条无描述条件都比正确描述得到更高分。无描述不是本次固定模板候选排名中的错误情绪负例，这不取消主测试结果；但它提醒我们：**目前观察到的是给定候选描述之间的排序信号，不能将这个分数直接当作不受约束的描述质量奖励。**不能据此声称“提供正确描述总能提高概率”。

## A 的数值问题在本次配置下已解决

| 检查 | BF16 v2 | FP32 v3 |
|---|---:|---:|
| 首帧逐步／并行最大差 | 0.0755825 | 0.00001812 |
| 相同 hidden 下子码本逐步／并行最大差 | 0.0503488 | 0.00001431 |
| 允许的替代路径误差 | 0.05 | 0.0001 |

FP32 检查在更严格阈值下通过；重复、padding、改变 padding 内容、未来帧对此前分数的影响均为 0。旧、新检查使用的 18 帧真实 codec 哈希相同，模型权重文件哈希也相同。改变的是前向计算精度，没有替换音频、标签或模型 checkpoint。结果支持此前阻塞与低精度计算路径有关，不应把它归因于情绪标注质量。

数值 audit 只在首个真实样本运行。表中的最大逐 token 误差与候选之间的平均分差是不同统计量，不能把前者机械当作所有样本分差的误差上界或置信区间。A003 仍应按敏感性结果保留为接近并列。

## B：流程通过，当前小样本未显示优于随机的信号

B 没有重新运行，完整复用了 v2：

| 样本 | 目标 | 人工最佳集合 | 模型首选 | 命中 |
|---|---|---|---|---|
| B001 | 开心 | A | D | 否 |
| B002 | 悲伤 | A、B、D | C | 否 |
| B003 | 愤怒 | B、C、D | C | 是 |
| B004 | 平静 | A、C、D | C | 是 |

命中 2/4＝50%；随机基线 `(1/4+3/4+3/4+3/4)/4=62.5%`。没有模型平局；默认及较大容差下结论不变。无全部不合格或无法判断的真实组，所以这批结果尚未覆盖这些情况。四组不足以判定 B 普遍无效，也不能把低于基线全部归因于数据。

A 的初步正向结果不能替代 B 的验证。当前结论是：**流程可用；A 值得用既定 pilot 进一步核验；B 尚未显示有用的择优信号；双向反馈均有效仍未成立。**不进入训练。
