# 第二轮音频相似度实验

完成 432 对音频、两个编码器的四种评分。

SpeechBERTScore 使用逐帧最大 cosine 的平均值（precision）；cosine 基线对同层特征先按时间平均。
两种方法使用同一编码器时共享同一份特征；层固定为 14。结果为原始 [-1,1] 分数。
